Дата: 3 октября 2026. Код Stealth Box: `0cede4b`.
Этот отчёт фиксирует завершённые локальные и интеграционные проверки;
успешность CI и публикация релиза здесь не подтверждаются.

## Остальные результаты

- Свежий полный `go test -race -count=1 ./...`: PASS; `go vet ./...`: PASS.
- Оба полных E2E-сценария: PASS — настоящий SSH, reverse Unix socket, rsync,
  tmux и переподключение, Mac Docker, Git worktrees и возврат артефактов.
- Шесть настоящих SSH-запусков двух checkout с одинаковым basename `api`:

  сохранение настроек bridge, Escape и восстановление ICANON/ECHO. SVG в README

  native Mac `--version` подтвердил v0.4.3. Это проверка сборки, не публикации.

## Сохранность и очистка

Git status/diff исходной рабочей копии, выбранные lock-файлы и выбранные hashes/inodes
`vendor` не изменились. Полного побайтового аудита всех untracked-файлов не было.
Состояния существовавших Docker-контейнеров не изменились; их volumes сохранены.
Созданные тестом контейнеры, сеть и volumes, включая anonymous, удалены.
SSH fixture, bridge/socket, временные ключи и конфиг удалены. Одноразовый checkout,
кэш зависимостей и отчёты остаются приватными.

## Границы

Прогон использовал локальный Linux SSH fixture. Новая облачная ВМ не выделялась;
отдельная свежая проверка подтвердила отсутствие ВМ и дисков в проверенной папке KZ.
Новые облачные ресурсы не создавались.

Не проверялись live-вызовы native LLM с удалённой авторизацией и полная Windows/WSL2
сессия. Ограниченная отмена локального SSH-процесса не доказывает уничтожение всех
удалённых descendants. Receipt отражает подготовленную попытку и результат sync;
успех команды определяется её кодом завершения, исходники не являются immutable snapshot.

Независимые council, модельные focus perspectives и judge выделили три группы
исправлений. Выполнены восемь циклов при лимите 20. Это модельная оценка;
исследования с людьми и измеренного улучшения usability не было.

В macOS CI исправлен только oracle теста отмены: пауза heartbeat за 150 мс
не доказывает завершение соседнего процесса. Проверка теперь учитывает Wait,
готовность и ограниченное ожидание прогресса; причина конкретной CI-паузы не установлена.

В следующем macOS CI такой же oracle обнаружен в тесте обновления занятого bridge.
Он исправлен с проверкой завершения запроса и ограниченным ожиданием heartbeat;
контрольные случаи различают паузу с продолжением, убитый процесс и живой процесс
без прогресса. Рабочий код bridge не менялся; причина конкретной CI-паузы неизвестна,
успешность следующего CI ещё не подтверждена.
